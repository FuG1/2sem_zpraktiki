# 2sem_zpraktiki

## Описание

Это демонстрационный веб-проект на Node.js, который показывает основы работы с сервером, обработку статических HTML-страниц и использование стилей на Sass и Bootstrap. Приложение отображает главную страницу с информацией о проекте и технологиях, а также страницу 404 для несуществующих маршрутов.

## Как запустить приложение

1. **Установите Node.js**  
   Скачайте и установите Node.js с [официального сайта](https://nodejs.org/).

2. **Клонируйте репозиторий или скачайте проект**  
   ```
   git clone <ссылка_на_репозиторий>
   cd 2sem_zpraktiki
   ```

3. **(Опционально) Скомпилируйте стили из SCSS в CSS**  
   Для этого потребуется установить Sass:
   ```
   npm install -g sass
   sass style.scss style.css
   ```
   После этого подключите `style.css` вместо `style.scss` в файлах `index.html` и `404.html`.

4. **Установите зависимости**  
   В данном проекте нет дополнительных зависимостей, кроме Node.js.

5. **Запустите сервер**  
   ```
   npm start
   ```
   или
   ```
   node server.js
   ```

6. **Откройте приложение в браузере**  
   Перейдите по адресу [http://localhost:3000](http://localhost:3000)

## Суть приложения

Приложение реализует простой HTTP-сервер на Node.js, который обслуживает главную страницу и страницу 404. Для оформления используются Bootstrap и собственные стили на Sass. Это отличный пример для изучения основ серверной разработки и работы с современными веб-технологиями.
